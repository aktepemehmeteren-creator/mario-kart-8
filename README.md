# Mario Kart PSP - Full 3D + Items + Languages

## Characters (6)
Mario, Luigi, Yoshi, Peach, Toad, Bowser — real 3D models

## Items (3D models)
- **Question Block** — Paper Mario item box
- **Banana Peel** — SSB Brawl trophy model
- **Koopa Shell** — SM64 early shell
- **Power Star** — SM64 star (star power orbit)
- **Knight Shield** — LBP3 shield (when shield active)

## Language
- **SELECT** on main menu toggles **TR / EN**
- All menus and item names bilingual

## Font
Times New Roman style (Liberation Serif Bold) with Turkish glyphs
